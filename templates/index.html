Quản trị

Tải lên file bảng điểm (Excel/CSV) hoặc nhập các môn đã học, chọn thêm kỹ năng mềm và lĩnh vực bạn quan tâm — hệ thống sẽ phân tích và gợi ý nhóm nghề cùng các nghề phù hợp nhất với bạn.

1. Bảng điểm 2. Kỹ năng 3. Sở thích
1. Bảng điểm học phần

Bạn có thể tải file bảng điểm Excel (.xlsx) hoặc CSV (.csv) để hệ thống tự động đọc điểm, hoặc nhập thủ công các môn đã có điểm. Môn chưa học có thể để trống.

Tải lên file bảng điểm Chỉ hỗ trợ file Excel (.xlsx) hoặc CSV (.csv)
Tệp:

File có thể thiếu môn chưa học; hệ thống dùng các môn nhận diện được có điểm trong khoảng 0–10. Có thể tải bảng điểm dạng dọc (cột TBCHP) hoặc dạng ngang (mỗi môn một cột).

Xem danh sách 12 môn học hệ thống nhận diện
    {% for s in subjects %}
  • {{ s.label }}
    • {% endfor %}

Nhập điểm các môn đã học theo thang điểm 0–10; để trống môn chưa học. Nếu tên môn trong chương trình của bạn khác, nhập điểm vào môn tương đương gần nhất.

{% for s in subjects %} {% endfor %}
2. Kỹ năng

Chọn mức độ cho từng kỹ năng (Yếu, Trung bình, Tốt, Xuất sắc). Kỹ năng để "Chưa đánh giá" sẽ không ảnh hưởng đến kết quả:

{% for skill in skill_options %}
{% endfor %}
3. Lĩnh vực bạn quan tâm

Chọn 1 hoặc nhiều lĩnh vực bạn thấy hứng thú nhất — sở thích của bạn sẽ được dùng để ưu tiên nhẹ khi xếp hạng nhóm nghề:

{% for interest in interest_options %} {% endfor %}

Kết quả là gợi ý dựa trên dữ liệu thống kê, không thay thế cho sự tìm hiểu và lựa chọn của chính bạn.
